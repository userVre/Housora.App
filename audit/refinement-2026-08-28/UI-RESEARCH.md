# UI research brief

## Context

- Product: visual interior-design workspace.
- Platform: responsive web app.
- Goal: make discovery, saving, project creation, and returning to work feel like one continuous loop.
- Constraints: preserve Housora’s dark architectural presentation-room visual system and its three-destination navigation.

## Shipped-product patterns

- Pinterest Saved/boards: every save has an obvious destination and visual collections remain browsable. Adopt the visible Saved collection and close-up image behavior.
- Adobe Firefly Favorites: generated outputs can be marked from results and retrieved from a dedicated collection with confirmation. Adopt action-aligned feedback and durable retrieval.
- Canva Projects/folders: saved work returns to an owning project surface. Adopt generated-design continuity into Projects without adding another global destination.

## Direction

- Keep Projects, Discover, and Saved as the only global destinations.
- Split Saved into Designs and Inspiration, with counts and distinct empty states.
- Pass a Discover reference directly into creation.
- Keep typography editorial for headings and operational for controls.
- Improve readability, keyboard behavior, focus management, and mobile touch targets without changing the brand palette.
